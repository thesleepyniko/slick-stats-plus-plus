# Slick Stats++

Slick Stats with faster music updates by grabbing data on device rather than from Last.fm. Currently only works on macOS, may eventually work on other devices.

> [!IMPORTANT]
> On macOS, Slick Stats++ uses media-control ~~(with an optional version to use nowplaying-cli)~~ (this is a WIP) This should work on later versions (i.e. Tahoe), but support is fragile due to reliance on private APIs. Slick Stats++ may stop working at any time on macOS, be warned.
